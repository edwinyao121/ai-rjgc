# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 业务背景与目标

航母吃水较深（典型吃水约12米），母港航道水深受限，需趁高潮位时段安全出港。本应用面向四大航母母港（诺福克、圣迭戈、布雷默顿、横须贺），自动采集未来72小时潮汐数据，基于吃水阈值12.8米识别可出港时间窗，并以四格仪表盘呈现各港当前潮高、出港条件与下一窗口倒计时，辅助调度员快速决策。

## 2. 目标用户

- 航母母港出港调度员
- 港口指挥与航海保障人员
- 舰队作训与航行计划参谋

## 3. 核心功能

1. **四港潮汐数据采集**：接入公开潮汐预测API（NOAA CO-OPS 覆盖诺福克/圣迭戈/布雷默顿；日本海上保安厅或等效源覆盖横须贺），获取未来72小时潮高序列。
2. **统一时区处理**：各港口本地时间统一换算为北京时间（UTC+8）展示与存储。
3. **可出港窗口识别**：对每港潮高曲线与12.8米阈值求交，识别连续满足阈值的区间，记录起止时间、峰值潮高与持续时间。
4. **四格仪表盘**：2×2栅格，每格显示港口名、当前潮高、是否满足出港条件（绿/红状态色）、下一个窗口起止时间。
5. **窗口倒计时**：窗口关闭时红色倒计时显示距离下一窗口开启的剩余时间；窗口开放时绿色高亮显示剩余持续时间。
6. **定时刷新**：每10分钟自动拉取最新潮汐数据并重算窗口，刷新时保留既有缩放视图。
7. **当前时间标线**：图表时间轴上以醒目亮色实线标注真实当前时间（北京时间），交互后不消失偏移。
8. **数据源标注与降级**：无真实API时以模拟/调和常数推算占位，界面徽章与接口data_source字段明确标注来源。

## 4. 数据需求

- **输入数据**：公开潮汐预测API（NOAA CO-OPS、日本海上保安厅等）、四港坐标与站码、航母吃水阈值12.8米。
- **输出数据**：每港当前潮高、出港条件布尔值、下一窗口起止时间、窗口倒计时、数据来源标识。
- **数据频率**：潮高采样间隔≤6分钟，整体刷新周期10分钟。

## 5. 页面与交互

- **四格仪表盘单页**：2×2栅格布局，深色科技风（主色#243340，卡片背景#1B2732）。
- **每格内容**：港口名（标题字体）、当前潮高数值（大字号）、出港条件徽章（绿/红）、下一窗口起止时间区间、倒计时数字。
- **可选趋势图**：每格可展开72小时潮高曲线，阈值线12.8米固定展示，窗口区间markArea着色，当前时间markLine标注。
- **交互**：窗口开放时绿色边框高亮，关闭时红色倒计时跳秒；hover显示窗口详情。

## 6. 验收标准

1. 四大港口未来72小时潮汐数据全部展示，无空缺。
2. 潮高≥12.8米的连续时段被正确识别为可出港窗口，起止时间标注。
3. 仪表盘每格显示港口名、当前潮高、出港条件、下一窗口起止时间；窗口开放绿色、关闭红色倒计时。
4. 数据每10分钟自动刷新，当前时间标线在缩放/拖拽后不消失偏移。
5. 横须贺等无真实API的港口以模拟数据占位并明确标注"模拟数据"徽章。
6. 四港时间统一为北京时间展示，时区换算无误。

## 7. 非功能需求

- 视觉遵循深色科技风设计规范，配色取自#243340系色板。
- 响应式适配常见分辨率，无横向滚动条与内容溢出。
- 文字横向排列，关键数值（潮高、窗口时间、倒计时、数据来源）完整可见不截断。
- 离线或潮汐API不可用时标注"时间不可靠"或"模拟数据"，不伪装真实数据。
