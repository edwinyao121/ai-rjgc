# 航母母港潮汐窗口计算器 - 需求规格说明书

## 1. 项目概述
### 1.1 业务背景
航母母港潮汐窗口计算器旨在为海军舰队调度人员提供四大航母母港（诺福克、圣迭戈、布雷默顿、横须贺）的实时潮汐状态监控和出港窗口计算能力，解决航母编队出港调度中对潮汐条件的精准、实时判断需求。

### 1.2 业务目标
- 自动化潮汐数据采集，替代人工查表
- 精准计算航母安全出港窗口（潮高≥12.8米）
- 一屏展示四大母港窗口状态，提升态势感知效率
- 倒计时辅助出航准备规划

### 1.3 目标用户
海军舰队调度人员、母港港务长、航母舰长及导航官、海军作战规划人员

## 2. 功能需求
### 2.1 潮汐数据采集
- 接入公开潮汐预测API（默认使用NOAA CO-OPS API）
- 支持配置四大港口的API站点ID
- 每次采集获取未来72小时逐时潮汐预测数据
- API不可用时降级使用本地模拟数据
- 数据来源和采集时间戳全程记录

### 2.2 窗口计算引擎
- 设定航母吃水阈值为12.8米
- 在72小时预测范围内标记所有满足潮高≥12.8米的时间段
- 输出每个窗口的起止时间和持续时间
- 当前时间处于窗口内时标记为窗口开放

### 2.3 四格仪表盘
- 每格对应一个港口，布局为2×2网格
- 每格显示：港口名称、当前实时潮高（米）、窗口状态（开放/关闭）、下一个窗口起止时间
- 窗口开放时背景/边框为绿色
- 窗口关闭时背景/边框为红色

### 2.4 倒计时功能
- 窗口关闭时显示距离下一个窗口开启的倒计时
- 倒计时格式：DD天 HH小时 MM分钟
- 精度到分钟级
- 倒计时归零时自动刷新窗口状态

### 2.5 自动刷新
- 每10分钟自动刷新一次潮汐数据和窗口状态
- 支持手动强制刷新
- 界面显示上次刷新时间戳
- 刷新期间不阻塞用户操作

### 2.6 数据来源标注
- 展示数据来源名称（如NOAA CO-OPS / 模拟数据）
- 展示数据采集时间戳
- 模拟数据模式下有醒目的模拟数据标识

## 3. 非功能需求
### 3.1 性能
- 页面加载时间不超过3秒
- 数据刷新时间不超过5秒
- 倒计时每秒更新无卡顿

### 3.2 兼容性
- 支持Chrome/Firefox/Edge最新版本
- 响应式设计，适配1920×1080及以上分辨率

### 3.3 可靠性
- API不可用时自动降级到模拟数据
- 降级时在前端明确标注
- 刷新失败不影响当前数据显示

## 4. 验收标准
1. 四大港口未来72小时潮汐数据可正确获取和显示
2. 吃水12.8米阈值窗口自动计算并准确标注
3. 四格仪表盘正确显示每格的全部内容（港口名、潮高、状态、窗口时间）
4. 窗口开放/关闭状态颜色正确切换（绿/红）
5. 窗口关闭时倒计时实时更新精度到分钟
6. 每10分钟自动刷新数据刷新时间戳正确更新
7. 模拟数据降级时明确标注模拟数据
8. npm test && npm run build 通过
