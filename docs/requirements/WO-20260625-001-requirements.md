# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 项目概述

### 1.1 业务目标
构建一个面向海军港口调度与航母作战规划人员的潮汐窗口计算工具，通过对接公开潮汐预测API，自动计算并可视化展示诺福克、圣迭戈、布雷默顿、横须贺四大航母母港的未来72小时可出港时间窗口，辅助出港决策与计划编排。

### 1.2 目标用户
- 海军港口调度人员
- 航母作战规划人员
- 母港值班军官

### 1.3 核心约束
- 技术栈：Vue 3 + TypeScript + Vite（前端）/ Python FastAPI（后端）
- UI风格：深色科技风
- 部署方式：单机可运行应用
- 数据来源：公开潮汐预测API（如NOAA Tides & Currents API）

## 2. 功能需求

### 2.1 潮汐数据接入（P0）
对接公开潮汐预测API，支持以下四个港口未来72小时的潮汐数据自动拉取：
- 诺福克（Norfolk, VA）
- 圣迭戈（San Diego, CA）
- 布雷默顿（Bremerton, WA）
- 横须贺（Yokosuka, Japan）

数据字段至少包含：时间戳（UTC+8）、潮高（米）。

### 2.2 出港窗口计算（P0）
- 吃水阈值：12.8米
- 窗口定义：潮高连续≥12.8米的时间段
- 输出内容：窗口开始时间、窗口结束时间
- 覆盖范围：未来72小时

### 2.3 四格仪表盘展示（P0）
每格卡片展示内容：
- 港口名称
- 当前潮高（最新实测值，单位米）
- 出港条件状态（满足/不满足）
- 下一个窗口起止时间（若存在）

### 2.4 状态指示与倒计时（P0）
- 窗口开放：卡片背景或边框显示绿色，标注"窗口开放中"
- 窗口关闭：卡片显示红色倒计时，格式为"HH:MM:SS"，精确到秒
- 倒计时实时更新（每秒刷新）

### 2.5 自动刷新机制（P1）
- 刷新间隔：每10分钟
- 刷新内容：重新拉取潮汐数据并重新计算窗口
- 刷新行为：平滑更新，无白屏或闪烁

### 2.6 异常处理（P1）
- API不可用：显示"数据更新中"降级提示，保留上次有效数据
- 数据缺失/异常：状态置为"数据异常"，卡片变灰
- 无窗口时段：显示"72小时内无满足条件的窗口"

## 3. 非功能需求

### 3.1 性能要求
- 窗口计算响应时间<3秒
- 页面首次加载时间<3秒
- 倒计时更新帧率≥1fps

### 3.2 可用性要求
- 仪表盘适配1920×1080及以上分辨率
- 状态颜色清晰可辨（考虑色觉障碍友好）

### 3.3 数据要求
- 所有时间展示为北京时间（UTC+8）
- API响应中的data_source字段标记数据来源类型

## 4. 数据来源

### 4.1 潮汐数据
- 优先使用NOAA Tides & Currents API（https://api.tidesandcurrents.noaa.gov/）
- 端口ID/坐标需预先配置
- 如API不可用，使用本地模拟数据降级并标记data_source

## 5. 验收标准

| 编号 | 验收项 | 判定标准 |
|------|--------|----------|
| AC1 | 数据准确性 | 各港口潮高数据与API源误差不超过5% |
| AC2 | 窗口计算 | 自动识别所有满足潮高≥12.8m的连续时段，无遗漏 |
| AC3 | 倒计时精度 | 倒计时秒级刷新，与实际时间偏差<1秒 |
| AC4 | 自动刷新 | 每10分钟自动更新数据，页面平滑过渡 |
| AC5 | 状态指示 | 窗口开放绿色/关闭红色切换正确 |
| AC6 | 异常降级 | API不可用时显示降级提示，不崩溃 |
