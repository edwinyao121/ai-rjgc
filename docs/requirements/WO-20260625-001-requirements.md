# 航母母港潮汐窗口计算器 - 需求规格说明书

## 1. 项目概述

### 1.1 业务目标
为航母作战值班军官提供四大母港（诺福克、圣迭戈、布雷默顿、横须贺）未来72小时潮汐窗口的实时态势感知与倒计时决策支持，将航母出港窗口从人工查阅潮汐表提升为自动化、可视化、秒级响应的智能仪表盘。

### 1.2 目标用户
- 航母作战值班军官（核心用户）
- 舰队出航调度人员
- 港口作业指挥官
- 舰艇航行规划参谋

### 1.3 核心价值
- 将出港窗口识别从人工查阅潮汐表（约15-30分钟/港）缩短至自动化秒级计算
- 一屏覆盖四大母港，全局态势一目了然
- 倒计时精确到秒，支持精确出航规划

## 2. 功能需求

### 2.1 多源潮汐数据集成
- 接入NOAA CO-OPS API获取诺福克、圣迭戈、布雷默顿潮汐预报
- 接入日本气象厅/海上保安厅API获取横须贺潮汐预报
- 统一归算至MLLW基准面，统一北京时间（UTC+8）
- 本地缓存机制，API故障时降级使用缓存数据

### 2.2 吃水阈值窗口计算
- 可配置航母吃水阈值（默认12.8米）
- 可配置安全富余水深（默认2米）
- 自动计算未来72小时满足条件的连续时间窗口
- 窗口精度：分钟级

### 2.3 四格仪表盘
- 四格2×2网格布局
- 每格包含：港口名称、当前潮高（m）、状态指示、下一窗口时间、倒计时
- 窗口开放时绿色面板 + '窗口开放中'标识
- 窗口关闭时红色面板 + 倒计时显示

### 2.4 自动刷新
- 每10分钟全量刷新潮汐数据
- 后台刷新、无缝切换、无闪烁
- 倒计时连续运行不受刷新影响

### 2.5 数据溯源与降级
- 数据来源标注（NOAA / JMA）
- 数据获取时间戳
- '真实数据 / 模拟数据'徽章
- API故障时黄色'数据延迟'降级模式

## 3. 验收标准

| 编号 | 标准 | 验证方式 |
|------|------|----------|
| AC1 | 四港潮汐数据可稳定获取并在仪表盘上正确显示 | 仪表盘加载确认每格有数据 |
| AC2 | 窗口计算逻辑与人工查表结果在±5分钟内一致 | 抽样对比3个时间点的窗口计算结果 |
| AC3 | 倒计时精确至秒，刷新时不中断、不重置 | 观察倒计时跨刷新周期的连续性 |
| AC4 | 潮高≥阈值时面板为绿色，＜阈值时为红色 | 手动验证潮高临界值的颜色切换 |
| AC5 | 模拟单港API故障，该港降级显示黄色'数据延迟' | 断开API后观察降级显示 |

## 4. 技术约束

- 前端：Vue 3 + TypeScript + 组合式API
- 后端：Python FastAPI
- 外部API：NOAA CO-OPS（US）、JMA/日本海上保安厅（横须贺）
- 刷新间隔：600秒
- 时间精度：分钟级（窗口计算）/ 秒级（倒计时）
