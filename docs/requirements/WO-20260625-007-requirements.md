"# 航母母港潮汐窗口计算器 - 需求规格说明书

## 1. 业务目标
为航母母港调度及指挥人员提供实时潮汐窗口计算与可视化工具，辅助航母出航决策，确保航母在满足吃水条件的潮高窗口内安全出港。

## 2. 目标用户
- 航母母港港口调度人员
- 航母出航规划参谋
- 海军后勤保障与航海指挥人员

## 3. 系统架构
- 前端：Vue 3 + TypeScript + Vite + Naive UI（深色科技风主题）
- 后端：Python FastAPI
- 数据流：公开潮汐预测API → FastAPI后端（定时抓取+缓存） → JSON API响应 → Vue3前端 → 四格仪表盘

## 4. 功能需求

### 4.1 公开潮汐API数据接入
- 接入公开潮汐预测API，获取四大航母母港未来72小时逐小时潮高数据
- 四个港口：诺福克（Norfolk）、圣迭戈（San Diego）、布雷默顿（Bremerton）、横须贺（Yokosuka）
- 后端缓存数据减少重复请求，数据延迟不超过30分钟

### 4.2 航母吃水阈值比对与窗口计算
- 默认吃水阈值：12.8米（可根据实际舰型调整）
- 逐小时比对潮高≥阈值的时间段，合并连续满足条件的小时形成可出港时间窗口
- 起止时间精确到分钟

### 4.3 四格仪表盘可视化
- 2×2 布局仪表盘
- 每格：港口名称、当前潮高（米）、出港条件状态（满足/不满足）、下一个可出港窗口起止时间
- 状态色码：窗口开放绿色，关闭红色

### 4.4 智能倒计时
- 窗口关闭时：显示距下一窗口开启的倒计时（天:时:分:秒）
- 窗口开放时：显示"可出港"状态及当前窗口剩余时间
- 倒计时每秒更新

### 4.5 自动刷新
- 每10分钟自动请求最新数据
- 刷新过程平滑无闪烁
- 可选手动刷新按钮

### 4.6 数据来源标注
- 页面明确标注数据来源
- API不可用时使用模拟数据降级并标注"模拟数据"

## 5. 非功能需求
- 页面首次加载时间不超过3秒
- API响应时间不超过2秒
- 适配1920×1080及以上分辨率
- 港口配置支持后续扩展
- 阈值支持运行时调整

## 6. 验收标准
1. 各港口独立显示当前潮高并与12.8米阈值比对，潮高单位米保留一位小数
2. 正确计算未来72小时内的可出港时间窗口，窗口起止时间精确到分钟
3. 倒计时精确显示距下一窗口的剩余时间，每秒更新
4. 窗口开放时绿色、关闭时红色，状态切换无异常
5. 页面每10分钟自动刷新一次数据，刷新过程平滑
6. 仪表盘在1920×1080分辨率下完整显示四格内容
