# 航母母港潮汐窗口计算器 · 需求规格说明书

## 1. 业务目标
构建一个面向航母编队指挥调度场景的潮汐窗口计算仪表盘，实时监测四大航母母港的潮汐数据，自动计算满足航母吃水深度（≥12.8m）的可出港时间窗口，以直观可视化方式辅助指挥官快速决策。

## 2. 目标用户
- 航母编队指挥员/作战参谋
- 港口调度管理军官
- 航母航行计划制定人员

## 3. 核心功能

### 3.1 公开潮汐API数据接入
- 接入 NOAA（美国国家海洋和大气管理局）或其他公开潮汐预报API
- 覆盖诺福克（Norfolk, VA）、圣迭戈（San Diego, CA）、布雷默顿（Bremerton, WA）、横须贺（Yokosuka, JP）四大港口
- 获取未来72小时逐小时潮高预测数据
- 数据获取失败时使用缓存数据降级

### 3.2 出港窗口计算
- 设定航母吃水阈值为 12.8 米
- 逐小时比对潮高数据，识别潮高 ≥ 12.8m 的时间段
- 合并连续满足条件的时间段为完整窗口
- 窗口起止时间精确到分钟

### 3.3 四格仪表盘
- 四个独立卡片分别展示四个港口状态
- 每个卡片包含：
  - 港口名称
  - 当前潮高（米）
  - 是否满足出港条件（是/否）
  - 下一可出港窗口起止时间
  - 72小时潮高趋势缩略图
  - 状态指示灯（绿色=窗口开放，红色=窗口关闭）

### 3.4 倒计时与状态指示
- 窗口开放时：绿色背景，显示"可出港"及窗口剩余时间
- 窗口关闭时：红色背景，显示距下一窗口开启的倒计时
- 倒计时格式：天:时:分:秒
- 每秒更新倒计时显示

### 3.5 潮高趋势图
- 每个港口卡片内嵌微型折线图
- X轴为时间（72小时），Y轴为潮高（米）
- 标注 12.8m 阈值线
- 满足出港条件的区域以高亮色块标记

### 3.6 多时区自适应
- 诺福克：UTC-5（EST）
- 圣迭戈/布雷默顿：UTC-8（PST）
- 横须贺：UTC+9（JST）
- 每格卡片标题栏显示时区标识
- 所有时间按港口本地时间显示

### 3.7 数据自动刷新
- 每10分钟自动拉取最新潮汐数据
- 刷新前保留上一轮数据，避免闪烁
- 刷新时显示加载状态
- 界面显示"上次更新时间"

### 3.8 数据来源标注
- 每个卡片底部标注数据来源类型
- 标识为"真实数据"、"模拟数据"或"缓存数据"
- 数据来源标识不允许用户混淆

## 4. 功能边界

### MVP 范围
- 四格仪表盘核心界面
- 潮汐API数据接入
- 窗口计算与状态指示
- 倒计时显示
- 自动刷新
- 数据来源标注
- 多时区适配
- 72小时趋势缩略图

### 后续扩展
- 日历时间轴视图
- 跨港口窗口对比排序
- 窗口导出/分享
- 自定义吃水阈值
- 潮汐历史数据统计
- 推送告警（邮件/短信）
- 地图模式展示

## 5. 数据与交互

### 输入数据
- NOAA CO-OPS API 潮汐预报数据（JSON格式）
- 各大港口的 Station ID 配置
- 吃水阈值（固定 12.8m，后续可配置）

### 主要页面
- **仪表盘主页**：四格布局，每格包含港口状态卡片
- **可选：窗口详情弹窗**：点击港口卡片展示更详细的潮汐数据和窗口列表
- **可选：日历视图页**：时间轴窗口总览

## 6. 验收标准
1. 页面加载后5秒内完成首次潮汐数据获取并展示
2. 四个港口卡片正确显示各自港口名、时区、当前潮高和状态
3. 窗口关闭时倒计时精确到秒，每秒更新
4. 窗口状态切换（开放→关闭或反之）时颜色/文字无延迟更新
5. 每10分钟自动刷新数据，刷新间隔误差不超过30秒
6. 数据来源标识清晰可见，模拟数据无法伪装为真实数据
7. 页面整体符合深色科技风设计规范
8. 各港口时间按本地时区正确显示，无时区混排错误
