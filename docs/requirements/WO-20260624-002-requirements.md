# 航母甲板风场条件评估系统

## 1. 项目概述

构建全球航母甲板风力条件实时评估可视化系统，通过接入气象风场数据，分析全球航母活动区域内风力条件是否满足舰载机起降要求。

## 2. 目标用户

航母作战决策人员、航空管制人员、军事态势分析人员。

## 3. 核心功能

### 3.1 风场数据接入与模拟
- 接入全球气象格点风场数据（初始阶段使用模拟数据替代真实 API）
- 数据包含 10 米高度风速（m/s 或 knots）和风向（度）
- 覆盖全球海域范围
- 数据更新频率：每 5 分钟

### 3.2 航母活动区域管理
- 维护全球已知航母的模拟位置数据列表
- 每艘航母的属性：名称、当前经纬度、最大航速（30 节）、当前航速、当前航向
- 支持手动添加/编辑航母信息

### 3.3 甲板风计算引擎
- 从格点风场中提取每艘航母所在位置的 10 米高度风速和风向
- 根据航母航速（0~30 节）和航向，叠加自然风速计算合成甲板风
- 舰载机起降所需甲板风最小值为 20 节
- 计算可实现的甲板风范围（航母通过调整航向/航速能达成的最大/最小甲板风）
- 判定每艘航母当前是否具备以下条件：
  - **无弹射器辅助起飞条件**：合成甲板风 ≥ 20 节
  - **安全着舰条件**：合成甲板风在一定范围内且侧风分量可控

### 3.4 可视化看板
- 全球地图展示所有航母实时位置
- 每艘航母以图标标注当前状态（绿色=双条件满足、黄色=仅满足一项、红色=均不满足）
- 点击航母图标展示详细数据面板：
  - 当前位置自然风速/风向
  - 当前航母航速/航向
  - 当前合成甲板风
  - 可实现的甲板风范围
  - 起降条件判定结果
- 时间轴控件支持查看历史数据回放

### 3.5 告警与通知
- 当航母进入/离开可起降条件区域时触发状态变更提示
- 以可视化方式（颜色闪烁、面板高亮）通知用户

## 4. 输入数据

| 数据项 | 说明 | 初始阶段 |
|--------|------|----------|
| 格点风场数据 | 全球 0.25°×0.25° 网格的 10m 风速/风向 | 模拟数据 |
| 航母位置数据 | 每艘航母的实时经纬度、航速、航向 | 模拟数据 |
| 航母静态属性 | 名称、最大航速（30 节） | 内置固定数据 |
| 舰载机起降参数 | 最小甲板风 20 节 | 内置参数 |

## 5. 主要页面

### 5.1 全局态势页面
- 世界地图（Mapbox/Leaflet/OpenLayers）
- 航母位置标注与状态着色
- 风场矢量图叠加（风向箭头 + 风速色温）
- 5 分钟自动刷新

### 5.2 航母详情面板
- 航母基本信息
- 实时气象数据
- 甲板风计算详情
- 起降条件状态
- 历史趋势图表

### 5.3 设置页面
- 航母位置管理（添加/编辑/删除模拟航母）
- 阈值参数配置（甲板风最小值等）

## 6. 技术栈建议

| 层 | 技术 |
|------|------|
| 前端框架 | React / Vue 3 |
| 地图组件 | Leaflet / Mapbox GL |
| 状态管理 | Zustand / Pinia |
| 后端（可选） | Node.js / Python FastAPI |
| 数据模拟 | Python 脚本生成模拟风场 + 航母轨迹 |
| 数据更新 | WebSocket 推送 / 轮询（5 分钟间隔） |

## 7. 验收标准

1. [ ] 全球地图可正确显示所有模拟航母位置
2. [ ] 每艘航母的状态颜色根据起降条件自动更新
3. [ ] 甲板风计算逻辑正确：自然风 + 航母航速矢量合成 ≤ 30 节
4. [ ] 无弹射器起飞条件（合成甲板风 ≥ 20 节）判定正确
5. [ ] 安全着舰条件判定正确
6. [ ] 数据每 5 分钟自动刷新
7. [ ] 点击航母弹出详情面板，数据完整
8. [ ] 航母位置和参数可通过设置页面编辑

## 8. 未来扩展

- 接入真实 GFS/ECMWF API 替代模拟数据
- 接入真实 AIS 船舶数据获取航母实际位置
- 支持更多机型起降参数配置
- 历史数据统计与报告导出
- 多用户协作与权限管理
