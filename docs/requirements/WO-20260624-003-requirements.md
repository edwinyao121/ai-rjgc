# 需求规格说明书：全球航母甲板风评估系统

## 1. 项目概述
### 1.1 目标用户
军事航空分析人员、航母作战研究人员、军事爱好者。

### 1.2 核心目标
接入全球气象格点风场数据，结合航母自身航速航向，计算每艘航母甲板风条件，判定是否满足舰载机无弹射辅助起飞和安全着舰的风力要求，以地图 + 卡片列表形式呈现，每 5 分钟刷新。

### 1.3 名词定义
| 术语 | 定义 |
|------|------|
| 甲板风 | 航母甲板上感受到的相对风速 = 自然风矢量 + 航母航速矢量 |
| 无弹射辅助起飞 | 舰载机仅依靠甲板风 + 自身推力即可起飞，无需弹射器助力 |
| 安全着舰 | 甲板风条件满足舰载机拦阻着舰的安全包线 |

## 2. 功能需求

### 2.1 数据层

#### 2.1.1 全球格点风场数据（Mock）
- **模拟数据源**：参考 NOAA GFS 0.25°×0.25° 全球网格，覆盖范围 90°N~90°S, 0°~360°E
- **数据字段**：每个格点包含 10m 高度风速（m/s）和风向（°），以 u/v 分量存储
- **刷新周期**：每 5 分钟生成一组新的模拟数据，数据之间保持连续性（平滑变化）
- **数据格式**：JSON，结构为 `{ "grid": { "lat": [...], "lon": [...] }, "time": "ISO8601", "data": { "u10": [[...]], "v10": [[...]] } }`

#### 2.1.2 航母活动区域数据
- **数据来源**：内置静态配置 JSON
- **覆盖航母**：
  - 美国：尼米兹号（CVN-68）、艾森豪威尔号（CVN-69）、卡尔文森号（CVN-70）、罗斯福号（CVN-71）、林肯号（CVN-72）、华盛顿号（CVN-73）、斯坦尼斯号（CVN-74）、杜鲁门号（CVN-75）、里根号（CVN-76）、布什号（CVN-77）、福特号（CVN-78）
  - 中国：辽宁舰（16）、山东舰（17）、福建舰（18）
  - 俄罗斯：库兹涅佐夫号
  - 英国：伊丽莎白女王号、威尔士亲王号
  - 法国：戴高乐号
  - 印度：维克兰特号、超日王号
- **每条记录包含**：船名、舷号、国家、当前坐标（lat/lon，模拟初始位置为母港或典型部署区）、航速（节）、航向（°）、最大航速（节）、舰载机类型

### 2.2 计算逻辑层

#### 2.2.1 格点风速提取
- 输入：航母当前坐标 (lat, lon)
- 方法：双线性插值，从周围 4 个格点的 u10/v10 插值得到该位置的自然风矢量 (u_nat, v_nat)
- 输出：100m 高度换算后的 10m 高度自然风速（m/s）和风向

#### 2.2.2 甲板风合成计算
- 航母自身速度矢量：根据航母航速（节）和航向（°）计算 (u_ship, v_ship)
- 合成：甲板风矢量 = 自然风矢量 + 航母速度矢量
- 甲板风速 = | (u_nat + u_ship, v_nat + v_ship) |（换算为节）
- **最大可达甲板风**：以航母最大航速 30 节沿最佳航向航行时，计算理论最大甲板风速

#### 2.2.3 起降条件判定
| 条件 | 判定 |
|------|------|
| 当前甲板风 ≥ 20 节 | 当前具备无弹射辅助起飞条件 |
| 当前甲板风 ≥ 20 节 | 当前具备安全着舰条件 |
| 最大可达甲板风 ≥ 20 节 | 调整航向航速后有机会满足条件 |
| 最大可达甲板风 < 20 节 | 不具备起降条件 |

### 2.3 展示层

#### 2.3.1 全球地图视图
- 渲染全球底图，叠加格点风场（风羽或色温流线）
- 标注所有航母当前位置（图标区分国家）
- 航母标记颜色：
  - 🟢 绿色：当前同时满足起飞和着舰条件
  - 🟡 黄色：调整航向后有机会满足
  - 🔴 红色：当前和最大可达均不满足
- 点击航母图标弹出详情卡片

#### 2.3.2 航母状态列表
- 表格视图，每行一艘航母
- 列：船名、国家、当前坐标、自然风速/风向、当前甲板风、最大可达甲板风、起飞条件、着舰条件、建议
- 支持按条件状态筛选（全部/可起飞/可着舰/不可用）
- 支持按甲板风排序

#### 2.3.3 更新机制
- 每 5 分钟自动刷新风场数据 → 重新计算全部航母 → 更新地图和列表
- 刷新时有视觉提示（计时器倒计时 + 刷新动画）
- 支持手动刷新

## 3. 数据处理流程
```
定时器（5min）
  → 生成模拟格点风场数据
  → 遍历所有航母
    → 双线性插值提取自然风
    → 合成当前甲板风
    → 计算最大可达甲板风
    → 判定起降条件
  → 更新 UI（地图 + 列表）
```

## 5. 验收标准

### 5.1 功能验收
1. 【风场模拟】系统启动后显示全球格点风场，数据每 5 分钟自动刷新，风速变化连续平滑
2. 【航母列表】正确显示所有配置航母的当前位置和状态
3. 【甲板风计算】点击任一航母，详情中显示自然风 → 合成甲板风 → 最大可达甲板风的完整计算链
4. 【条件判定】甲板风 ≥ 20 节时标记绿色/可起飞可着舰；＜20 节但最大可达 ≥ 20 节时标记黄色；均＜20 节时标记红色
5. 【更新机制】5 分钟倒计时准确，刷新时数据更新且 UI 重绘

### 5.2 非功能验收
1. 单次计算周期（风场生成 + 全部航母计算 + UI 更新）≤ 2 秒
2. 页面在 Chrome/Firefox/Edge 最新版正常渲染
3. 离线状态下模拟数据正常运行

## 6. 技术方案建议
| 层次 | 技术栈 | 说明 |
|------|--------|------|
| 前端框架 | React + TypeScript | 组件化，易于维护 |
| 地图渲染 | Leaflet 或 Mapbox GL JS | 轻量地图库，支持标注和风场图层 |
| 状态管理 | Zustand | 轻量，适合中等复杂度状态 |
| 构建工具 | Vite | 现代前端构建，HMR 快速 |
| 数据模拟 | 内置 mock 引擎 | 独立模块，后续可无缝替换为真实 API |
| 可视化 | D3.js（风场流线） | 格点风场渲染 |
