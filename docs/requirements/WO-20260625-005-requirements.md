# 航母母港潮汐窗口计算器 - 需求规格说明书

## 1. 项目概述

### 1.1 业务背景
航母母港出港作业受潮汐条件严格制约。航母吃水深度较大（约12.8米），低潮时港口航道水深不足可能危及航行安全。本系统通过接入公开潮汐预测API，自动计算并可视化展示四大航母母港的可出港时间窗口，辅助指挥人员快速决策。

### 1.2 目标用户
航母母港调度指挥人员、海军作战保障人员

### 1.3 覆盖港口
| 港口 | 位置 | 驻泊航母 |
|------|------|----------|
| 诺福克（Norfolk） | 美国东海岸弗吉尼亚州 | 杜鲁门号、艾森豪威尔号等 |
| 圣迭戈（San Diego） | 美国西海岸加利福尼亚州 | 卡尔·文森号、林肯号等 |
| 布雷默顿（Bremerton） | 美国西海岸华盛顿州 | 卡尔·文森号（维修）等 |
| 横须贺（Yokosuka） | 日本神奈川县 | 里根号/华盛顿号（前沿部署） |

## 2. 功能性需求

### 2.1 潮汐数据接入
- 接入公开潮汐预测API（推荐NOAA CO-OPS及日本气象厅/WorldTides补充横须贺数据）
- 支持诺福克、圣迭戈、布雷默顿、横须贺四个港口
- 获取未来72小时（至少每6分钟一个采样点）潮汐预测数据
- 每10分钟自动刷新
- 支持数据源不可用时的优雅降级和错误提示

### 2.2 出港窗口计算
- 设定航母吃水安全阈值为12.8米
- 自动识别潮高 ≥ 12.8 米的时间区间作为可出港窗口
- 标记各港口的当前可用窗口和下一可用窗口的起止时间（北京时间UTC+8）
- 计算距下一窗口的剩余时间（倒计时，精确到秒）

### 2.3 四格仪表盘展示
- 2×2网格布局，每格为一个港口状态卡片
- 每张卡片包含：
  - 港口中文名称
  - 当前实时潮高（米，保留两位小数）
  - 出港条件状态徽章（可出港/不可出港）
  - 下一可用窗口起止时间（ISO 8601格式）
  - 距下一窗口倒计时
  - 数据来源标签（实时数据/模拟数据）
  - 上次刷新时间
- 窗口开放时：卡片背景为绿色系
- 窗口关闭时：卡片背景为红色系，倒计时数字突出显示
- 响应式设计，适配监控大屏和桌面端

### 2.4 数据标注与刷新
- 每条数据明确标注 data_source: real / simulated
- 显示上次刷新时间
- 支持手动强制刷新按钮
- 自动刷新间隔10分钟，刷新时保留上次数据避免闪烁

## 3. 非功能性需求

### 3.1 性能
- 数据加载时间不超过5秒
- 倒计时实时更新（秒级精度）
- 页面初始加载时间不超过3秒
- 每次API请求数据量控制在1MB以内

### 3.2 可靠性
- 7×24小时持续运行
- 数据源不可用时展示上次有效数据并提示数据可能延迟
- 支持网络断线后的自动重连

### 3.3 可维护性
- 港口配置（名称、API Station ID、经纬度）集中在配置文件中
- 吃水阈值可通过配置文件调整
- 刷新间隔可配置

## 4. 验收标准

1. 仪表盘同时加载并正确显示4个港口的潮汐数据和状态
2. 潮高 ≥ 12.8米时自动标记为出港窗口开放（绿色），< 12.8米时标记为窗口关闭（红色+倒计时）
3. 倒计时精确到秒并实时更新，视觉效果流畅
4. 数据每10分钟自动刷新一次，刷新后状态正确更新
5. 数据来源（实时/模拟）和刷新时间在每个卡片中明确标注
6. 页面首次加载时间 ≤ 3秒（基于模拟数据时）
7. 数据源不可用时有清晰的降级提示
