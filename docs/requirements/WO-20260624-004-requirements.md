# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 项目概述
基于公开潮汐预测 API，为四大航母母港（诺福克、圣迭戈、布雷默顿、横须贺）计算未来 72 小时满足航母安全出港条件的时间窗口，并以四格仪表盘形式实时展示，每 10 分钟刷新。

## 2. 目标用户
海军基地调度员、港口作业指挥人员、航母出港计划制定与监控相关人员。

## 3. 核心功能
1. 接入公开潮汐预测 API：
   - 诺福克 / 圣迭戈 / 布雷默顿：NOAA CO-OPS API（真实数据）
   - 横须贺：日本气象厅潮汐预报或同等公开数据源；无法获取时使用调和常数推算并标注「模拟数据」
2. 抓取四大母港未来 72 小时潮汐预测数据
3. 设定航母吃水阈值 12.8 米；按港口海图基准水深计算实际水深 = 海图基准水深 + 潮高，当水深 ≥ 12.8 米时判定为「可出港窗口」
4. 计算并显示下一个可出港窗口的起止时间
5. 倒计时显示距离下一个窗口开启的剩余时间
6. 每 10 分钟自动刷新潮汐数据，倒计时每秒更新

## 5. 页面与交互
- 单页面四格仪表盘（2×2 网格布局）
- 每格展示内容：
  - 港口名
  - 当前潮高（米）
  - 当前水深（米）
  - 是否满足出港条件（是/否徽章）
  - 下一个可出港窗口起止时间（北京时间 UTC+8）
  - 窗口状态：
    - 窗口开放中 → 绿色边框 + 「窗口开放」徽章
    - 窗口关闭中 → 红色倒计时显示距离下一个窗口开启的剩余时间
- 顶部显示数据来源徽章（真实数据 / 模拟数据）+ 最后更新时间
- 每 10 分钟自动刷新

## 6. 输入数据
- 潮汐预测 API 数据（NOAA CO-OPS / 日本气象厅等公开数据源）
- 港口坐标与海图基准水深（配置项）
- 航母吃水阈值：12.8 米（可配置）
- 数据抓取窗口：未来 72 小时

## 7. 验收标准
- [ ] 仪表盘正确显示四个港口的当前潮高与水深
- [ ] 正确计算并标注可出港窗口（水深 ≥ 12.8m）
- [ ] 窗口开放时显示绿色状态徽章，关闭时显示红色倒计时
- [ ] 倒计时实时更新（每秒）
- [ ] 数据每 10 分钟自动刷新
- [ ] 数据来源明确标注（真实数据 / 模拟数据徽章）
- [ ] 时间统一以北京时间（UTC+8）展示
- [ ] 四大港口数据来源清晰可追溯

## 8. 技术约束
- 前端：Vue3 + TypeScript + Naive UI（深色科技风，主色 #243340）
- 后端：FastAPI
- 时区统一北京时间（UTC+8）
- 真实数据优先，模拟数据需明确标注
- 接口响应提供 data_source 字段标明数据来源（noaa / jma / simulated / harmonic）
- 时间窗口用状态色块/徽章明显标记，不得与普通时间点混淆
