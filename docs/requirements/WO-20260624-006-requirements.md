# 航母母港潮汐窗口计算器 需求规格说明书

## 一、产品概述
四格仪表盘，实时展示诺福克、圣迭戈、布雷默顿、横须贺四大航母母港的未来 72 小时潮汐数据与「可出港时间窗」，每 10 分钟自动刷新，窗口开放时绿色、关闭时红色倒计时。

## 二、目标用户
- 航母编队航行调度员、港口港务值班员、海军作战指挥中心参谋。

## 三、核心功能
1. 抓取四港未来 72 小时潮汐预测数据，每 10 分钟自动刷新。
2. 依据「港口基准水深 + 实时潮高 ≥ 12.8 米」判定可出港条件。
3. 自动标出各港口满足条件的「可出港时间窗」（连续满足且时长 ≥ 30 分钟）。
4. 倒计时显示距离下一个窗口还有多久，窗口开放时显示剩余时长。
5. 四格仪表盘：港口名 / 当前潮高 / 是否满足出港条件 / 下一个窗口起止时间。
6. 窗口开放=绿色，关闭=红色倒计时。

## 四、数据源
| 港口 | 坐标 | 数据源 | 站点/Key |
|------|------|--------|----------|
| 诺福克 Norfolk | 36.9475, -76.3289 | NOAA CO-OPS | 8638154 |
| 圣迭戈 San Diego | 32.7157, -117.2964 | NOAA CO-OPS | 9410170 |
| 布雷默顿 Bremerton | 47.5665, -122.6330 | NOAA CO-OPS | 9445133 |
| 横须贺 Yokosuka | 35.2831, 139.6684 | WorldTides（优先）→ 调和常数推算（兜底，标注「模拟数据」） | 需配置 API Key |

- 接口响应含 `data_source` 字段：`noaa` / `worldtides` / `simulated`。
- 前端据 `data_source` 展示「真实数据 / 模拟数据」徽章。

## 五、判定逻辑
- 航母吃水阈值 T = 12.8 米。
- 各港基准水深（MLLW 以上，推荐值）：诺福克 11.5 m / 圣迭戈 10.8 m / 布雷默顿 11.2 m / 横须贺 11.0 m。
- 满足出港条件：`基准水深 + 当前潮高 ≥ 12.8 米`。
- 连续满足时段聚合为窗口，窗口长度 ≥ 30 分钟方为有效。

## 六、页面与交互
- **顶部**：标题「航母母港潮汐窗口计算器」+ 全局下次刷新倒计时 + 手动刷新按钮。
- **主体 2×2 仪表盘**，每格卡片：
  - 港口名 + 当地时间 + 北京时间（辅助）。
  - 当前潮高数值（米）+ 72h 潮位曲线迷你 ECharts 面积图。
  - 状态徽章：可出港（绿色）/ 不可出港（红色）。
  - 下一个窗口起止时间（北京时间，markArea 着色 + 端点竖线）。
  - 距下一窗口倒计时（关闭时）/ 窗口剩余时长（开放时）。
  - 数据来源徽章（真实 / 模拟）。
- **底部**：Leaflet 卫星底图（Esri World Imagery）小地图，标注四港位置，点击定位到对应卡片。
- 每 10 分钟自动刷新。

## 七、时间与时区
- 全部统一北京时间（UTC+8）展示与存储。
- 卡片同时显示当地时区时间作为辅助。
- 时间窗口起止列 + 状态色块明显标记，不与普通时间点混淆。

## 八、验收标准
1. 四格仪表盘正确加载，10 分钟内自动刷新潮汐数据。
2. NOAA 三港显示「真实数据」徽章，横须贺按 `data_source` 显示对应徽章。
3. 满足出港条件时卡片绿色，窗口起止时间准确到分钟。
4. 关闭状态下红色倒计时正确递减，窗口开放时显示剩余时长。
5. 所有色值取自设计规范色板（主色 #243340、卡片 #1B2732、文字 #E5EAFF/#C9D2D9/#CCDAFF），Naive UI 深色主题。
6. GIS 底图为卫星影像，叠加半透明深色蒙版。
7. 前端 `npm run lint` / `typecheck` 通过，后端 `ruff check` 通过。
8. 启动前检测端口占用并顺延，后端 CORS 放行前端实际端口。

## 九、技术栈与接口
- 前端：Vue3 `<script setup>` + TS + Naive UI + ECharts + Leaflet + Pinia + axios。
- 后端：FastAPI + uvicorn，端口检测从 8000 顺延。
- API：
  - `GET /api/v1/tides` 返回四港汇总。
  - `GET /api/v1/tides/{port}` 返回单港 72h 潮位序列与窗口列表。
  - 统一响应 `{code, message, data}`，含 `data_source` 字段。
- 启动端口：前端 5173（顺延）、后端 8000（顺延），端口变更同步 CORS 与 baseURL。
