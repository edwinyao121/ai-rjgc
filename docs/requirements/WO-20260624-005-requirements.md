# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 项目概述
为航母出港决策提供潮汐窗口辅助判断工具，接入公开潮汐预测 API，实时计算并展示四大航母母港（诺福克、圣迭戈、布雷默顿、横须贺）未来 72 小时内满足航母吃水要求（12.8 米）的可出港时间窗，以四格仪表盘形式呈现并支持倒计时与自动刷新。

## 2. 目标用户
- 航母母港调度与作业人员
- 港口海事决策辅助岗

## 3. 核心功能
1. **潮汐数据采集**：接入公开潮汐预测 API（美国港口使用 NOAA CO-OPS，横须贺使用日本海事公开潮汐源；无法获取时使用模拟数据并明确标注），抓取四大港口未来 72 小时潮汐预测数据。
2. **窗口计算**：基于航母吃水阈值 12.8 米，将潮高 ≥ 12.8 米的连续时段识别为"可出港时间窗"。
3. **倒计时显示**：实时显示距离下一个窗口开启或关闭的倒计时。
4. **状态标识**：窗口开放时绿色高亮，关闭时红色倒计时。
5. **定时刷新**：每 10 分钟自动刷新一次潮汐数据与窗口状态。

## 4. 输入数据
- 数据源：公开潮汐预测 API（NOAA CO-OPS / 日本海事公开潮汐源）
- 覆盖港口：
  - 诺福克 Norfolk（36.946°N, 76.329°W）
  - 圣迭戈 San Diego（32.686°N, 117.127°W）
  - 布雷默顿 Bremerton（47.568°N, 122.632°W）
  - 横须贺 Yokosuka（35.286°N, 139.674°E）
- 时段：未来 72 小时
- 阈值：航母吃水 12.8 米
- 时区：统一换算为北京时间（UTC+8）展示与存储

## 5. 主要页面与交互
### 5.1 四格仪表盘（主页）
- 2×2 网格布局，每格对应一个港口
- 每格内容：
  - 港口名（中英双语）
  - 当前潮高（米，实时数值）
  - 出港条件是否满足（是/否）
  - 下一个窗口起止时间（北京时间，明显区间标记：状态色块 + 端点竖线标注）
  - 状态色块：开放=绿色边框/徽章；关闭=红色边框 + 倒计时
- 数据来源徽章：真实数据 / 模拟数据

### 5.2 倒计时
- 窗口开放中：显示距离关闭的剩余时间
- 窗口关闭中：显示距离下一个窗口开启的剩余时间
- 格式：HH:MM:SS

### 5.3 时间窗口标记规范
- 起止时间以明显区间标识（状态色块 + 端点标注），不得与普通时间点混淆
- 卡片边框/徽章按窗口状态着色（开放=绿、关闭=红）

## 6. 验收标准
1. 仪表盘正确加载四个港口数据，无空白格
2. 潮高数值与公开 API 数据一致（误差 ≤ 0.1 米）
3. 窗口计算正确：潮高 ≥ 12.8 米的连续时段被识别为可出港窗口
4. 窗口开放时显示绿色，关闭时显示红色倒计时
5. 每 10 分钟自动刷新，刷新后数据与窗口状态更新
6. 所有时间统一为北京时间展示
7. 真实/模拟数据来源明确标注（data_source 字段 + 前端徽章）
8. 深色科技风 UI，色值严格遵循设计规范（主色 #243340）

## 7. 技术约束
- 前端：Vue3 + TypeScript + Naive UI（darkTheme）+ ECharts
- 后端：FastAPI + uvicorn，API 统一 `/api/v1` 前缀，响应 `{code, message, data}`
- 设计规范：深色科技风（主色 #243340，卡片 #1B2732）
- 端口：前端 5173、后端 8000（占用则自动顺延并同步 baseURL/CORS）
- 接口响应提供 `data_source` 字段（noaa / simulated / harmonic 等）

## 8. 数据来源说明
- 美国三港：NOAA CO-OPS API（真实数据）
- 横须贺：优先日本公开潮汐源；无法获取时使用调和常数推算或模拟数据并标注「模拟数据」
- 前端依据 `data_source` 展示真实/模拟数据徽章
