# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 业务背景
航母母港的潮汐条件直接影响航母进出港的安全性。美军航母吃水深度约12.8米，当实时潮高低于该阈值时出港存在搁浅风险。本系统通过接入公开潮汐预测API，为四大航母母港提供未来72小时的可出港窗口计算与可视化仪表盘。

## 2. 业务目标
- 自动化采集全球四大航母母港潮汐数据
- 以12.8米吃水阈值为基准计算可出港时间窗口
- 以四格仪表盘形式实时呈现各港口出港条件
- 通过颜色编码和倒计时辅助快速决策

## 3. 目标用户
- 航母编队调度指挥人员
- 母港港口值班军官
- 航海保障与气象水文分析人员

## 4. 数据来源
- 公开潮汐预测API（如NOAA CO-OPS API 或其他全球潮汐预报源）
- API请求频率：每10分钟一次
- 数据覆盖范围：未来72小时逐时潮高

## 5. 核心功能

### 5.1 潮汐数据采集
- 自动定时请求潮汐API
- 支持诺福克、圣迭戈、布雷默顿、横须贺四个站点的潮汐数据
- 异常重试与超时处理

### 5.2 窗口计算引擎
- 以12.8米为阈值判断每个时刻潮高是否达标
- 连续达标时段标记为可出港窗口
- 输出窗口起止时间

### 5.3 四格仪表盘
| 港口 | 当前潮高 | 状态 | 窗口时间 |
|------|----------|------|----------|
| 诺福克 | 1.2m | 关闭 | 下一窗口：06:00-08:00 |
| 圣迭戈 | 1.5m | 开放 | 剩余：2h30m |

### 5.4 状态指示
- 窗口开放：绿色背景+剩余时间
- 窗口关闭：红色背景+距下窗口倒计时

### 5.5 自动刷新
- 每10分钟自动拉取最新数据
- 仪表盘无感更新

## 6. 主要页面
- 单页面四格仪表盘（4-panel dashboard）
- 每格包含：港口名、当前潮高、状态标识、窗口时间、倒计时

## 7. 验收标准
1. 四大港口数据可同时展示在一个视图中
2. 潮高数据来源为公开API，标记数据来源或模拟标识
3. 窗口计算逻辑正确：潮高≥12.8m且持续至少1小时
4. 状态颜色正确切换：满足条件→绿色，不满足→红色
5. 倒计时精确到秒级实时更新
6. 每10分钟自动刷新且数据变化正确反映到界面

## 8. 非功能性需求
- 响应时间：首屏加载<3秒
- 刷新间隔：600秒
- 故障降级：API不可用时显示上一次有效数据并标记数据状态
