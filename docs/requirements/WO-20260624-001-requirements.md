# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 项目概述
构建一个面向航母出港调度的潮汐窗口计算器，接入公开潮汐预测 API，实时抓取诺福克、圣迭戈、布雷默顿、横须贺四大航母母港未来 72 小时潮汐数据，根据航母吃水 12.8 米阈值自动标注「可出港时间窗」，以四格仪表盘形式展示，每 10 分钟刷新一次。

## 2. 目标用户
- 航母出港调度指挥员 / 调度参谋
- 港口调度中心值班人员

## 3. 业务必要性与预期成效
- **业务必要性**：用于航母出港调度辅助决策，为指挥员提供直观的潮汐窗口判断依据，替代人工查询潮汐表与心算窗口，支撑多港口并行监控。
- **预期成效**：提升出港安全，减少人工查询潮汐表的时间，实现四港统一调度视野与倒计时预警。

## 4. 核心功能
1. 接入公开潮汐预测 API：优先 NOAA CO-OPS（覆盖美国三港）；横须贺若无公开 API，使用调和常数推算并明确标注数据来源。
2. 抓取四大母港未来 72 小时潮汐数据：
   - 诺福克 Norfolk（美国东海岸）
   - 圣迭戈 San Diego（美国西海岸）
   - 布雷默顿 Bremerton（美国华盛顿州）
   - 横须贺 Yokosuka（日本）
3. 以航母吃水阈值 12.8 米为门槛，计算各港口满足条件的「可出港时间窗」（潮高 ≥ 12.8 米的连续时段）。
4. 倒计时显示：距离下一个可出港窗口的剩余时间（天/时/分/秒）；窗口开放时显示窗口剩余时长。
5. 四格仪表盘：每格显示港口名、当前潮高、是否满足出港条件、下一个窗口起止时间。
6. 窗口状态着色：窗口开放（当前处于可出港时段）显示绿色；关闭时显示红色倒计时。
7. 每 10 分钟自动刷新一次数据，顶部显示刷新倒计时。

## 5. 输入数据
- **潮汐数据源**：公开潮汐预测 API（NOAA CO-OPS 为真实来源；横须贺标注来源字段）。
- **参数配置**：
  - 航母吃水阈值：12.8 米（可在配置中调整）
  - 预测时长：未来 72 小时
  - 刷新周期：10 分钟
- **港口坐标**：四港经纬度，用于 GIS 地图定位。

## 6. 技术架构
- **前端**：Vue 3（script setup + TypeScript）+ Vite + Naive UI（深色科技风）+ Pinia + Vue Router
- **后端**：FastAPI + uvicorn，统一响应 {code, message, data}
- **GIS 地图**：Leaflet（卫星底图，标注四港位置与窗口状态）
- **图表**：ECharts（72 小时潮汐曲线 + 阈值线 + 窗口 markArea）
- **HTTP**：axios
- **端口**：前端 5173、后端 8000，启动前检测占用并顺延，后端端口变更同步前端 baseURL，CORS 放行前端实际端口。

## 7. 页面与交互
### 主页面布局
- 顶部标题栏：应用名称 + 北京时间时钟 + 数据来源徽章（真实/模拟）+ 刷新倒计时。
- 中部四格仪表盘（2×2 网格）：
  - 每格卡片：港口名 / 当前潮高（米）/ 出港条件状态徽章（绿=可出港/红=不可出港）/ 下一个窗口起止时间 + 倒计时。
  - 窗口开放：卡片边框绿色高亮并显示窗口剩余时长；关闭：红色倒计时大字。
- 下部区域：
  - 左：Leaflet 卫星地图，标注四港 marker，点击切换详情，marker 颜色随窗口状态变化；
  - 右：ECharts 72 小时潮汐曲线（所选港口），阈值线 12.8 米，markArea 着色可出港窗口，端点竖线标注窗口边界。
- 卡片层次：#1B2732 → #243340 → #2E3F4D 逐级递进。

### 交互
- 点击地图 marker 或仪表盘卡片切换右侧潮汐曲线港口。
- 悬停窗口区间显示起止时间与时长。

## 8. 设计规范
- 主色 #243340，标题文字 #E5EAFF，次要文字 #C9D2D9，辅助文字 #CCDAFF。
- 卡片背景 #1B2732，二级卡片 #243340 10% 透明，组织元素 #2E3F4D，描边 rgba(187,203,217,0.35)。
- 字体：标题 YouSheBiaoTiHei 26px；卡片标题 OPPO Sans 4.0 中 14px；内容 14px；辅助 12px。
- Naive UI darkTheme + themeOverrides 定制（frontend/src/theme.ts）。
- 窗口状态色：开放=绿色系，关闭=红色系，取自科技风色板。

## 9. 时间与时区
- 四港分属不同时区（东海岸 ET、西海岸 PT、日本 JST），后端统一转换为北京时间（UTC+8）输出与存储。
- 接口时间戳 ISO 8601 传输，前端按北京时间格式化显示。
- 时间窗口（可出港起止区间）必须在列表、图表、卡片三处采用明显标记：起止时间区间列 + 状态色块；ECharts markArea 着色区间 + 端点竖线；卡片状态色边框/徽章/倒计时，不得与普通时间点混淆。

## 10. 数据来源标识
- 接口响应提供 data_source 字段：noaa（真实）/ simulated（模拟）/ harmonic（调和常数推算）。
- 前端据此在标题栏与卡片显示「真实数据 / 模拟数据」徽章，不得与真实数据混淆。

## 11. 验收标准
1. 四格仪表盘正确展示四港：港口名、当前潮高、出港条件状态、下一个窗口起止时间。
2. 窗口开放时绿色边框/徽章并显示窗口剩余时长；关闭时红色倒计时。
3. 每 10 分钟自动刷新，顶部刷新倒计时可见。
4. 72 小时潮汐曲线含 12.8 米阈值线与窗口区间 markArea 及端点竖线。
5. Leaflet 卫星底图标注四港，点击 marker 切换详情，marker 颜色随窗口状态变化。
6. 横须贺若使用模拟/调和数据，明确标注「模拟数据」徽章。
7. 全部时间统一北京时间显示，窗口区间明显标记。
8. 全站深色科技风，颜色取自设计规范色板，无规范外色值。
9. 前端 npm run lint / typecheck 通过，后端 ruff check 通过。
