# 航母母港潮汐窗口计算器

## 1. 项目概述

航母母港潮汐窗口计算器是一个单机可用的四格仪表盘工具，用于实时监测诺福克、圣迭戈、布雷默顿、横须贺四大航母母港的潮汐数据，自动计算航母吃水阈值（12.8米）下的可出港时间窗口。

## 2. 目标用户

航母港口调度人员、航海指挥官、舰艇出航规划人员。

## 3. 业务必要性

现有流程中，判断航母是否可出航需要人工查询潮汐表并手动计算潮高是否满足12.8米吃水要求，效率低且易出错。本工具自动完成数据获取、条件判断和窗口计算，消除人工计算环节。

## 4. 预期成效

将人工计算耗时从数分钟缩短至实时秒级显示，避免因人工计算错误导致船舶搁浅风险。

## 5. 核心功能

- 接入公开潮汐预测API，抓取四个港口的未来72小时潮汐数据
- 设定航母吃水阈值为12.8米
- 自动标出各港口满足条件的可出港时间窗
- 倒计时显示距离下一个可用窗口的时间
- 四格仪表盘展示各港口状态
- 每10分钟自动刷新数据

## 6. 数据来源

- 公开潮汐预测API（无需密钥的公开数据源）
- 四大港口：诺福克（Norfolk）、圣迭戈（San Diego）、布雷默顿（Bremerton）、横须贺（Yokosuka）

## 7. 主要页面/交互

单一页面，四格仪表盘布局：
- 每格显示：港口名称、当前潮高、是否满足出港条件、下一个窗口起止时间
- 窗口开放时该格背景显示绿色，倒计时显示距窗口关闭时间
- 窗口关闭时该格背景显示红色，倒计时显示距下一个窗口开放时间
- 顶部或角落显示数据来源标识和最后刷新时间

## 8. 验收标准

- 正确接入潮汐API并解析四个港口数据
- 12.8米阈值判断准确
- 时间窗口计算精确到分钟
- 倒计时实时更新
- 绿色/红色状态正确切换
- 每10分钟自动刷新
- 应用可正常启动运行
