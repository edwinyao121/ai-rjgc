# 航母母港潮汐窗口计算器需求规格说明书

## 1. 业务目标
构建面向航母母港调度场景的潮汐窗口计算器，接入公开潮汐预测API，自动计算并可视化四大航母母港未来72小时可出港时间窗，帮助调度人员快速准确把握出港时机。

## 2. 目标用户
- 航母编队调度人员
- 港口作业指挥官
- 舰队战备值班人员

## 3. 核心功能
1. 接入公开潮汐预测API（NOAA CO-OPS等）抓取四港潮汐数据
2. 按航母吃水阈值12.8米计算可出港时间窗
3. 四格仪表盘可视化：港口名、当前潮高、出港条件状态、下一窗口起止时间
4. 窗口开放显示绿色，关闭显示红色倒计时
5. 每10分钟自动刷新数据与窗口状态
6. 数据来源标注（真实/模拟徽章）

## 4. 数据与输入
- 数据源：公开潮汐预测API（NOAA CO-OPS等）
- 港口：诺福克、圣迭戈、布雷默顿、横须贺
- 时间范围：未来72小时潮汐预测序列
- 阈值参数：航母吃水12.8米

## 5. 主要页面与交互
- 单页四格仪表盘
- 每格对应一个港口，展示港口名、当前潮高、出港条件状态、下一窗口起止时间
- 窗口开放时整格高亮绿色，关闭时红色倒计时
- 顶部显示最后刷新时间与数据来源徽章

## 6. 验收标准
1. 成功抓取并展示四港未来72小时潮汐数据
2. 窗口计算以12.8米阈值为准
3. 仪表盘四格正确显示各港口信息
4. 窗口开放显示绿色、关闭显示红色倒计时
5. 每10分钟自动刷新生效
6. 数据来源徽章清晰标注真实或模拟
7. 深色科技风UI符合设计规范

## 7. 技术约束
- 前端Vue3 + TypeScript + Vite + Naive UI
- 后端FastAPI + uvicorn
- API统一/api/v1前缀，响应统一{code, message, data}
- 端口：前端5173，后端8000，启动前检测占用
- 公开源不得硬编码商业授权瓦片或密钥
