# 航母母港潮汐窗口计算器 需求规格说明书

## 1. 项目概述

### 1.1 业务背景
航母出港作业对潮汐条件有严格要求。航母吃水深度约12.8米，当潮高不足时航母无法安全出港。目前依赖人工查阅多个港口的潮汐数据，效率低下且容易出错，无法快速评估多基地实时出港可行性。

### 1.2 项目目标
开发四格仪表盘应用，实时展示诺福克、圣迭戈、布雷默顿、横须贺四大航母母港未来72小时潮汐数据，自动识别潮高>=12.8米的时间窗口，以可视化方式提示操作员当前出港条件是否满足，并以倒计时显示距下一窗口剩余时间。

## 2. 目标用户
海军港调人员、航母作战值班军官、舰队调度中心操作员

## 3. 核心功能

| 编号 | 功能名称 | 功能描述 |
|------|---------|---------|
| F01 | 潮汐数据抓取 | 接入公开潮汐预测API，定时获取四大母港未来72小时潮高时序数据 |
| F02 | 阈值窗口计算 | 以12.8米为阈值，自动计算各港口满足吃水条件的时间窗口（含起止时间） |
| F03 | 当前状态展示 | 显示各港口当前潮高、与阈值差值、是否满足出港条件 |
| F04 | 四格仪表盘 | 四个卡片并排/田字布局，分别展示一个港口的完整信息 |
| F05 | 窗口状态指示 | 窗口开放时卡片绿色标识，窗口关闭时红色标识并显示倒计时 |
| F06 | 自动刷新 | 每10分钟自动拉取最新潮汐数据并更新界面 |
| F07 | 数据来源标识 | 明确标注数据为真实数据或模拟数据 |

## 4. 输入数据
- 公开潮汐预测API（如NOAA Tides & Currents API等）
- 目标港口：诺福克(Norfolk,VA)、圣迭戈(San Diego,CA)、布雷默顿(Bremerton,WA)、横须贺(Yokosuka,Japan)
- 预测时长：72小时
- 阈值参数：12.8米

## 5. 主要页面/交互

### 5.1 四格仪表盘（单页应用）
- 页面标题居中显示航母母港潮汐窗口计算器
- 四个卡片区域，2x2网格或4列布局
- 每个卡片包含：
  - 港口名称
  - 当前潮高数值(米)
  - 当前出港状态(可出港/不可出港)
  - 下一个可用窗口起止时间(ISO 8601)
  - 倒计时(距下一窗口打开/关闭)
  - 状态色块：绿色=窗口开放，红色=窗口关闭
- 全局刷新时间戳显示上次更新时间

## 6. 验收标准

| 编号 | 验收标准 |
|------|---------|
| AC01 | 四个港口卡片均正确显示当前潮高及与12.8米阈值的关系 |
| AC02 | 准确标出未来72小时内所有满足潮高>=12.8米的出港时间窗口 |
| AC03 | 窗口开放时卡片显示绿色并标注窗口剩余时长；关闭时显示红色并显示距下一窗口倒计时 |
| AC04 | 页面自动每10分钟刷新数据，刷新后倒计时重置 |
| AC05 | 数据来源明确标识为模拟数据或真实数据 |

## 7. 技术约束
- 前端：Vue 3 + TypeScript + Vite + Naive UI(深色科技风)
- 后端：Python FastAPI
- 时间格式：统一使用北京时间UTC+8
- API路径：/api/v1/*
- 响应格式：{code, message, data}
