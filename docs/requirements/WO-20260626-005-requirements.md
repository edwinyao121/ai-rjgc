# 航母舰载机态势感知系统 需求规格说明书

## 1. 业务目标
通过融合 AIS（船舶自动识别系统）与 ADS-B（广播式自动相关监视）数据，自动识别航母位置及其周边舰载机，建立「航母—舰载机」归属关系，为海军态势感知提供一目了然的可视化决策支持。

## 2. 目标用户
- 海上态势感知值班员/指挥参谋
- 舰载机飞行调度员
- 情报分析员

## 3. 核心功能
1. AIS 数据接入与航母位置识别
2. ADS-B 数据接入与飞机动态解析
3. 舰载机归属判定（空间邻近 + 高度低于 200 米）
4. GIS 卫星地图态势展示
5. 历史轨迹回放
6. 数据来源与置信度标注

## 4. 数据输入
- AIS 数据：航母 MMSI/船名、经纬度、航向、航速、时间戳
- ADS-B 数据：飞机 ICAO24/呼号、经纬度、高度、航向、时间戳
- 数据来源形式：实时 API 或离线文件（默认按文件读取，兼容实时接入）

## 5. 主要页面与交互
- 态势感知主界面：GIS 卫星底图 + 航母/舰载机图标 + 归属连线 + 图层切换
- 详情面板：点击航母/舰载机查看动态详情
- 历史回放：时间轴拖拽回放
- 列表视图：航母—舰载机归属关系列表

## 6. 核心算法
舰载机归属判定：
- 条件1：飞机与航母水平距离 ≤ R（建议默认 5 海里，可配置）
- 条件2：飞机飞行高度 < 200 米
- 同时满足则判定为该航母的舰载机

## 7. 验收标准
1. 航母位置在地图上实时可见，刷新延迟符合数据源周期
2. 飞机动态信息完整呈现，编号可检索
3. 舰载机归属判定准确率 ≥ 90%（与人工标注样本对比）
4. 归属关系在地图与列表中清晰可见
5. 真实数据与模拟数据均明确标注
6. 支持历史时段回放

## 8. 非功能要求
- 深色科技风视觉规范（主色 #243340）
- 时间统一为北京时间（UTC+8）
- GIS 底图使用卫星影像
- 多航母、多舰载机并发展示不卡顿
