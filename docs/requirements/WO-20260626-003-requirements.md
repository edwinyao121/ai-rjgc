# 航母舰载机态势感知系统 需求规格说明书

## 1. 概述

### 1.1 业务目标
通过融合AIS（船舶自动识别系统）与ADS-B（广播式自动相关监视）公开数据，自动识别全球航母位置，并基于航母周边低空飞机（高度<200米）判定舰载机归属关系，为海上态势感知与情报分析提供可视化支撑。

### 1.2 目标用户
- 海上情报分析人员
- 态势感知值班操作员
- 军事研究与教学人员

## 2. 核心功能

### 2.1 航母位置获取与展示
- 读取AIS数据，按已知航母MMSI/船名清单匹配识别航母，获取经纬度、航向、航速、时间戳。
- 在GIS卫星底图（Esri World Imagery）上以专属深色图标展示航母当前位置。
- 支持显示航母历史轨迹（可切换时间窗口）。

### 2.2 舰载机识别与归属判断
- 读取ADS-B数据，获取飞机编号（ICAO hex/航班号）、经纬度、高度、航向、速度、时间戳。
- 对每艘航母，扫描其周边半径R（默认50海里，可配置）内的飞机。
- 若飞机高度低于200米，判定为该航母的舰载机，建立“航母→舰载机”归属关系。
- 一架飞机同时只归属一艘航母（按距离最近或高度最低者优先）。

### 2.3 航母-舰载机关联展示
- GIS地图以航母为中心聚合展示所属舰载机；点位密集时启用cluster聚合。
- 点击航母展开舰载机列表（编号、高度、位置、航向、数据来源），地图与列表联动。
- 卡片/看板展示航母战斗群概览（舰名、舷号、位置、舰载机数量、最近更新时间）。

### 2.4 数据来源与可靠性标注
- 接口响应携带data_source字段（如ais_public / adsb_public / simulated）。
- 界面以徽章展示“真实数据/模拟数据”。
- 数据缺失或时间不可靠时标注“数据不可靠/时间不可靠”。

### 2.5 历史轨迹回放
- 选择航母或舰载机，回放近7天/30天轨迹与高度变化。
- 时间轴可拖拽，标注归属变化时刻（从过路飞机转为舰载机的时刻）。
- 图表含“当前时间”标线（北京时间，固定展示，不因交互消失）。

## 3. 数据与交互

### 3.1 输入数据
- AIS数据：公开AIS数据源（船位、MMSI、船名、航向、航速、时间戳）。
- ADS-B数据：公开ADS-B数据源（飞机ICAO hex、编号、位置、高度、航向、速度、时间戳）。
- 航母基准清单：已知航母MMSI/船名/舷号对照表（全覆盖，无数据时模拟占位并标注）。

### 3.2 主要页面
- 态势总览页：GIS卫星底图 + 航母/舰载机点位 + 战斗群卡片。
- 航母详情页：舰载机列表 + 轨迹回放 + 高度时序图。
- 舰载机详情页：编号、归属航母、实时位置、历史轨迹。

### 3.3 交互方式
- 地图缩放/拖拽、点位聚合展开。
- 点击点位弹出详情卡片。
- 时间轴拖拽回放。
- 数据来源徽章查看。

## 4. 验收标准
1. 系统能正确读取并解析AIS与ADS-B数据，解析成功率≥99%。
2. 地图上展示的航母数量不少于真实在役航母数量（按基准清单全覆盖，无数据时以模拟值占位并标注“模拟”）。
3. 对每艘航母，系统能正确识别周边200米以下飞机为舰载机，归属关系随数据刷新实时更新。
4. GIS地图使用卫星底图，深色科技风，点位聚合在低缩放层级下不重叠堆叠。
5. 每条记录带数据来源标识，模拟数据明确标注“模拟数据”。
6. 历史轨迹可回放近7天，时间轴可拖拽，归属变化时刻有明显标记，当前时间标线固定展示。
7. 前端npm run lint、npm run build与后端ruff check均通过。

## 5. 非功能需求
- 时区统一北京时间（UTC+8），当前时间取真实系统时钟，不硬编码。
- 配色严格遵循深色科技风设计规范（主色#243340）。
- 字体使用YouSheBiaoTiHei（标题）与OPPO Sans 4.0（正文）。
- 后端API统一/api/v1前缀，统一响应{code, message, data}。
