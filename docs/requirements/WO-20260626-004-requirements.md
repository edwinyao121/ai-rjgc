# 航母舰载机态势感知系统 需求规格说明书

## 1. 业务目标
基于AIS与ADS-B实时数据，自动识别航母位置及其周边低空飞行的舰载机，建立并动态维护"航母-舰载机"所属关系，以GIS地图与结构化列表两种形态提供态势感知展示，替代人工研判，提升海上态势情报生成时效与准确性。

## 2. 目标用户
- 海军舰艇指挥与作战值班人员
- 航母飞行甲板调度员
- 海上态势监视与情报分析岗位

## 3. 核心功能
1. AIS航母位置实时获取与地图标绘
2. ADS-B飞机数据采集与解析（编号、高度、位置、速度、航向）
3. 舰载机自动识别：航母周边+飞行高度<200米双重判定
4. 航母-舰载机所属关系动态维护与变更追溯
5. GIS卫星地图态势感知可视化（含点位聚合、关系连线）
6. 所属关系分组列表与搜索筛选
7. 历史关系变更查询与态势回放

## 4. 数据与交互
### 4.1 输入数据
- AIS船舶动态数据：航母MMSI、经纬度、航向、航速、时间戳
- ADS-B飞机广播数据：ICAO24编号、呼号、经纬度、气压高度/几何高度、速度、航向、时间戳

### 4.2 主要页面与交互
- **GIS态势感知主界面**：卫星底图+深色蒙版，标注航母与舰载机点位，关系连线，悬浮显示编号/高度，支持缩放、点位聚合、按航母筛选
- **所属关系分组列表页**：按航母分组树形展示下挂舰载机，含编号、高度、距离、关系建立时间，支持展开折叠与搜索
- **单艘航母详情视图**：展示该航母信息及其下挂舰载机实时清单
- **历史关系变更与态势回放页**：按时间轴回放航母-舰载机关系变化轨迹

## 5. 核心算法规则
- 以航母实时位置为圆心，设定周边判定半径R（建议默认10海里，可配置）
- 对该半径内飞行高度<200米的飞机判定为该航母舰载机
- 飞机离开半径或高度≥200米时自动解除关系
- 关系建立/解除均记录时间戳与原因

## 6. 验收标准
1. 航母位置定位误差<500米，位置刷新延迟≤30秒
2. ADS-B飞机编号与高度字段解析完整率100%，数据延迟≤15秒
3. 航母周边高度<200米飞机自动判定为舰载机，准确率≥95%，误判率<5%
4. 所属关系随实时数据动态更新，关系状态与真实态势偏差≤1分钟
5. GIS主界面一屏展示全部航母及关联舰载机，点位刷新无明显卡顿
6. 列表按航母分组树形展示，字段完整不截断，响应≤1秒
7. 关系变更可追溯，历史态势可回放

## 7. 非功能要求
- 时区统一北京时间（UTC+8）
- 数据源字段标注真实/模拟来源
- 配色遵循深色科技风设计规范（主色#243340）
- GIS底图使用卫星影像

## 8. MVP边界
- MVP：AIS/ADS-B接入、200米判定、关系动态维护、GIS主界面、分组列表
- 后续扩展：历史回放、多航母协同分析、关系预测、告警推送
