# 智能软件工厂原型系统·会话重构总结 (Session Summary)

本文件系统地记录了本次会话中围绕「智能软件工厂」原型系统进行的多次深度 UX 重构与功能演进。我们以 **“可视、可信、可控”** 的人机协同研发理念为核心，成功将原本零散、不一致的交互体系，升级为了高内聚、现代化、体验一致的智能软件工厂指挥平台。

---

## 1. 核心重构与功能实现 (Key Implementations)

### ① 大一统侧边栏交互规范化 (Unified Context Sidebar)
- **痛点**：此前的系统存在三种混杂的 AI 对话/详情弹出模式（全局右侧抽屉、思维导图局部抽屉、产出物内联 Flex 分栏），导致用户心智模型割裂，视觉体验零散。
- **重构方案**：
  - 彻底废弃所有局部的绝对定位抽屉和内联对话框，将屏幕最右侧统一划分为**“全局智能侧边栏”** (`#agentPanel`)。
  - 在 `router.js` 中新增并全局暴露了 `window.openSidebar(config)` 方法，支持动态传入 `title`、`subtitle`、`contentHtml` 及 `showInput`（输入框开关）。
  - 所有交互入口（门禁协助、导图节点检视、产出物优化）统一复用这一侧边栏，通过动态调整其状态，完美实现 **“左侧主屏全景阅览，右侧智能副屏协同”** 的现代 AI 辅助研发（如 Cursor / VSCode）标准交互范式。

### ② 阶段流水线白屏故障排查与修复 (Blank Screen Hotfix)
- **问题描述**：在侧边栏重构后，由于模板字符串拼接中残留了不规范的转义反斜杠（`\`），导致 `pipeline-render.js` 解析时抛出致命的 `SyntaxError`，致使阶段流水线页面完全白屏。
- **修复措施**：精确定位语法错误位置，剔除多余的转义符号，并通过 `node -c` 本地语法校验，迅速将界面恢复至正常工作状态。

### ③ 产出物上下文动态同步优化 (Dynamic Artifact-Sidebar Context Sync)
- **体验提升**：
  - 用户切换到 **「产出物」** 页签时，右侧侧边栏自动滑出，且副标题默认标识为 **“当前聚焦: [阶段名称]”**（如“当前聚焦: 代码审查”）。
  - 当用户在列表中点击具体的产出物文件（如 `QueryOptimizer.java`），或者通过活动日志链接跳转时，右侧侧边栏的副标题会实时联动更新为 **“当前聚焦: [具体文件名]”**。
  - 这一机制明确了 Agent 优化的上下文边界，大幅提升了“人机协同修改代码”时的交互确定性。

### ④ 项目级「我的评审」界面与角标联动 (Project-Level "My Reviews")
- **功能点**：
  - 在进入具体项目空间后，在左侧项目内侧边栏中新增了 **「项目评审」** 导航菜单，并附加了红色待办角标。
  - 重构了 `reviews.js` 渲染逻辑：自动识别当前上下文是否处于项目内。若在项目空间内，标题会自动变为“项目评审”，且数据源会被自动过滤，**仅展示属于当前项目关联任务的评审项**。
  - 更新了 `data.js` 的 `updateBadges()` 逻辑，使全局“我的评审”角标与各项目内“项目评审”的角标能够根据各自的数据范围精准联动更新。

### ⑤ 「可视、可信、可控」智能协同指挥中心工作台重构 (Unified "Cockpit" Dashboard)
- **痛点**：原有 Dashboard 基于传统的“堆砌图表+指标卡”设计，缺乏新用户的引导，且无法突出智能软件工厂“白盒化质控”的产品灵魂。
- **重构方案**：彻底推翻传统布局，在 `dashboard.js` 中构建了一个沉浸式的 **指挥中心 (Cockpit)**：
  - **顶部引导与待办区 (Hero & Action Center)**：
    - *左侧横向三步上手指南*：用大字报和卡片式设计引导新用户完成“建立项目 -> 设定门禁 -> 启动流水线”的研制闭环。
    - *右侧待办中心*：直观提炼当前用户急需解决的阻断门禁、待处理评审，让老手有明确的协同抓手。
  - **中部三大核心价值支柱**：
    - **👁️ 可视 (Observability)**：提供高对比度的终端风格“实时动态滚动播报屏”，配合生成代码量和调用次数，让 AI 所有的暗箱操作跃然纸上。
    - **🛡️ 可信 (Verifiability)**：展示安全漏洞扫描、架构合规检查等“六大质量门禁健康度”，用硬性的通过率数据消除对 AI 产出代码的安全顾虑。
    - **🕹️ 可控 (Controllability)**：列出当前“被阻断挂起”的高危节点，并附带醒目的 **【立即干预】** 按钮，点击直接精准跳转，彻底将掌控权留给人类开发者。
  - **底部快速访问区**：提供高颜值的活跃项目快速直达表格。
